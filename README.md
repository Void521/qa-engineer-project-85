# Тестирование в продакшене

[![hexlet-check](https://github.com/Void521/qa-engineer-project-85/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/Void521/qa-engineer-project-85/actions)

Протестируйте проект, который уже работает в продакшене

Учебный проект Хекслета: https://ru.hexlet.io/programs/qa-engineer
Как это должно работать: https://codebattle.hexlet.io/

## Стек

**[Codebattle](https://codebattle.hexlet.io/)** — игра с открытым исходным кодом для программистов, в которой два игрока одновременно решают одну алгоритмическую задачу на выбранных языках программирования. Побеждает тот, кто первым напишет рабочее решение, проходящее все тесты.

## Содержимое репозитория

* `requirements.yml` — описание функциональных, нефункциональных и неявных требований проекта.
* `test-cases.yml` — подробные тест-кейсы для проведения тестирования.
* `testing-report.yml` — результат прохождения тест-кейсов с отметкой об их успешности или провальности.
* `issues.yml` — открытые баг-репорты.
* `reopened_issues.yml` — неисправленные баги.

## О Хекслете

[Хекслет](https://ru.hexlet.io/) — школа программирования: авторские программы обучения с практикой, поддержкой наставников и реальными проектами, которые остаются в резюме. Этот репозиторий — один из таких проектов.
